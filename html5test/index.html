Practicar el uso de multimedia en HTML5, integrando un vídeo de YouTube con controles personalizados y un diseño creativo.

En esta actividad vas a incrustar un vídeo de YouTube, diseñar una “televisión” con HTML + CSS y crear tus propios controles con JavaScript.

¿Qué vas a hacer?

  1. Insertar un vídeo de YouTube en tu página usando la API de iframes.
  2. Diseñar una “televisión” con HTML + CSS:
    • marco
    • pantalla
    • patas o base
    • estilo personalizado
  3. Añadir controles personalizados en JavaScript:
    • ▶ Play
    • ⏸ Pausa
    • 🔇 Mute / Unmute
    • (opcional) ⏹ Stop
  4. Conectar los botones a la API para controlar el vídeo.
Controles personalizados

Estos botones usan la API de iframes de YouTube para controlar el vídeo.
